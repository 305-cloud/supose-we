# Ayoo — Portfolio Site

Portfolio site for **Ayoo** (@_Bethdesigns) — websites and brand systems
for authors: author sites, illustration/character art, and the Author
Launch Kit.

## What's here

- `index.html` — the full site, self-contained (all portfolio images and
  the Azshael promo video embedded as data URIs, no external assets
  besides system fonts).

## Sections

- Hero
- What I build (author websites, Launch Kit, illustration, reader tools)
- Recent work — geoffnelder.com case study, plus a strip of past site
  builds (The Haunted Law Firm, Azshael, geoffnelder.com)
- Illustration & cover art gallery
- Free tools — KDP Royalty Tracker (teaser, not yet linked)
- Illustration CTA
- Email signup (not yet wired to a mailing list)
